Markdown для Telegram с предпросмотром

Пишите исходный текст во вкладке Markdown и сразу проверяйте оформление. RichPost использует Rich Markdown для rich-сообщений Telegram; это формат с заголовками и таблицами, а не только старый MarkdownV2.

Один пример для начала

# Встречаемся в субботу

**Начало в 10:00.** Возьмите блокнот.

> Хорошие идеи начинаются с разговора.

- Обсудим планы
- Ответим на вопросы

[Подробности](https://example.com/meeting)

В предпросмотре будут заголовок, выделенное время, цитата, список и ссылка. Замените пример своим текстом и настоящим адресом перед публикацией.

Порядок работы

  1. Создайте черновик и выберите Markdown. Вставьте пример или используйте панель сниппетов.
  2. Проверьте результат справа. На телефоне перейдите на вкладку «Предпросмотр».
  3. Сохраните черновик. Укажите канал и отправьте тест себе через «Мне в личку».
  4. При отличии разбора откройте «Как разобрал Telegram». Можно перенести полученные блоки в визуальный режим; исходный текст останется в своей вкладке.

Типичные неожиданности

Один перенос внутри абзаца становится пробелом. Для нового абзаца нужна пустая строка; для переноса строки — два пробела в конце строки или обратная косая черта. Двойные подчёркивания дают жирный текст. Для подчёркивания используйте HTML-тег <u>…</u>.

Формулы, таблицы и разрешённые HTML-теги расширяют формат. Неизвестную конструкцию сначала проверьте в предпросмотре и личных сообщениях: локальный рендер не заменяет разбор Telegram.

Переключение вкладки не переписывает автоматически текст другого формата. Редактируйте и проверяйте тот формат, который собираетесь отправлять: он указан над редактором.
