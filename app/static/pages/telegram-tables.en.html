How to create a table in Telegram

Use a table for a price list, timetable or comparison. RichPost lets you build one visually or paste Markdown and check the result beside the editor.

Example: a meeting timetable

Two columns make the day and start time easy to find. The table is part of the message rather than a screenshot with tiny text.

Meeting timetable
DayStarts at
Monday10:00
Wednesday18:30

Paste Markdown into the editor

| Day | Starts at |
|---|---|
| Monday | 10:00 |
| Wednesday | 18:30 |
  1. Open RichPost and create a draft. Choose the Markdown tab.
  2. Paste the example and replace its values. Check columns and labels in the preview.
  3. Select a connected channel. Send preview sends a test post only to your direct messages: start the bot first.
  4. Publish now or choose a time from the Publish menu.

When to use visual mode

Add a Table block, then add rows and columns. Click a cell to change alignment, make it a header or merge it. You can paste a range from Google Sheets or Excel into a cell.

Markdown tables have borders and striped rows. Use visual mode or HTML for other options. Browser preview helps with layout; check important posts in Telegram before publishing. Rendering also depends on the Telegram client.

Keep the column count manageable and check readability on a phone. Split long comparisons into smaller tables.
