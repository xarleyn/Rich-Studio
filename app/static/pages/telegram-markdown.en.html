Telegram Markdown editor with preview

Write in the Markdown tab and check formatting as you go. RichPost uses Rich Markdown for Telegram rich messages, with headings and tables, rather than just the older MarkdownV2 format.

A starting example

# See you on Saturday

**Starts at 10:00.** Bring a notebook.

> Good ideas start with a conversation.

- Discuss our plans
- Answer your questions

[Details](https://example.com/meeting)

The preview shows a heading, a highlighted time, a quote, a list and a link. Replace the example with your text and a real destination before publishing.

Check before publishing

  1. Create a draft and choose Markdown. Paste the example or use the snippet toolbar.
  2. Check the preview on the right. On a phone, switch to the Preview tab.
  3. Save the draft. Select a channel and use Send preview to send a test to yourself.
  4. If parsing differs, open Telegram's result. You can use Telegram's returned blocks in visual mode; your source text remains in its tab.

Common surprises

A single newline within a paragraph becomes a space. Use a blank line for a new paragraph, or two trailing spaces or a backslash for a line break. Double underscores produce bold text. For underline, use the HTML tag <u>…</u>.

Formulas, tables and allowed HTML tags extend the format. Check unfamiliar syntax in the preview and your direct messages: the local renderer does not replace Telegram's parser.

Switching tabs does not automatically rewrite another format's source. Edit and check the format you intend to send; the editor identifies the active format above your content.
