Telegram Markdown with a live preview

Write in the Markdown tab and check formatting beside your source. RichPost uses Rich Markdown for rich Telegram messages, including headings and tables. Its rules differ from regular MarkdownV2.

Start with a small example

A short announcement can show a heading, an emphasized time, a quote, a list and a link. Copy this text into a new draft, then replace the subject, time and address with your own details.

# See you on Saturday

**Starts at 10:00.** Bring a notebook.

> Good ideas begin with a conversation.

- Discuss our plans
- Answer questions

[Details](https://example.com/meeting)

The preview should show a separate heading, a bold time, a quote and two list items. The example.com address is for demonstration. Replace it with a real link and check its destination before publishing.

Rich Markdown and MarkdownV2

Markdown is a name shared by several formats. Instructions for the regular Bot API using parse_mode=MarkdownV2 do not transfer directly to this editor. Rich messages have their own content structure, including headings, lists and tables. Pasting source text into a regular chat is also not equivalent to sending a rich post through the editor.

Start with a small set of familiar constructs. Test a new construct by itself before adding it to a longer post. This makes it easier to identify the cause when a line break, link or emphasis does not appear as expected.

Work through the post in the editor

  1. Create a draft and select Markdown. Paste the example or insert a construct from the snippets panel.
  2. Check the result on the right. On a narrow screen, open Preview to inspect the full post.
  3. Save the draft, start the bot and send a preview to your private chat. This does not publish the post to the selected channel.
  4. If the result differs, inspect how Telegram parsed the message and compare the returned structure. Update the source and check again.
  5. Select a channel, verify links and buttons, then publish now or choose a future time.

Understand line breaks and emphasis

A paragraph versus a new line

A single line break inside a paragraph becomes a space. Leave an empty line for a new paragraph. To break a line within the same paragraph, use two trailing spaces or a backslash. If a post looks too dense, check paragraph spacing before adding extra tags.

Bold text and underlining

Double asterisks produce bold text. Double underscores also mean bold emphasis, not underlining. For an underline, use the supported HTML tag <u>…</u> and check the result. Do not paste scripts or the layout of an entire web page into your post.

Switching between formats

When you switch between visual blocks, HTML and Markdown, the editor tries to convert the post content. If a construct cannot be transferred without losing data, the switch is cancelled and the original content is preserved. Read the editor's message, then continue in the original format or simplify the part it identifies.

JSON is applied through a separate action. Unapplied source changes should not be treated as the published version. Before sending, check the active format, the preview and the saved draft.

A final check before publishing

Read the rendered post without looking at its source. Are the headings clear? Are list items separate? Can readers find the intended next action? Check the real destinations of links and the selected channels. The local preview is useful while editing, but Telegram's parser and the reader's client also affect the final appearance.

For rows and columns, try the table example. You can schedule a finished draft or let an AI agent work with it through MCP.

Frequently asked questions

Do regular MarkdownV2 rules apply?

Not completely. RichPost uses Rich Markdown for rich messages. Check new constructs in the preview and a private Telegram test message.

Why did a line break disappear?

A single break within a paragraph becomes a space. Use a blank line for a new paragraph, or two trailing spaces or a backslash for a line break.

What should I do if a format switch is cancelled?

The editor preserves your original content when conversion without data loss is unavailable. Continue in the original format or simplify the identified construct.
