Подключение ИИ агента к Telegram через MCP

Агент может готовить черновики, показывать предпросмотр и заполнять ваши шаблоны в RichPost. Вы продолжаете работу в редакторе, а права агента задаёте персональным токеном.

Что даёт подключение

MCP позволяет совместимому клиенту вызывать инструменты RichPost из разговора с агентом. Можно поручить подготовку анонса, изменение черновика или создание поста по сохранённому шаблону. Результат остаётся в вашей учётке, поэтому текст можно открыть в обычном редакторе и проверить вручную.

Для подключения к размещённому сервису не нужно запускать свой сервер или скачивать приложение. Нужен клиент с поддержкой удалённого MCP через HTTP и персонального bearer токена. Если клиент работает только через OAuth, эта схема подключения ему не подойдёт. Возможность установить skill тоже зависит от клиента.

Что написать агенту

Отправьте клиенту, который поддерживает такие подключения, следующую задачу. В ней есть инструкция по настройке и отдельная проверка результата.

Подключи мне RichPost. Прочитай инструкцию для агента по адресу __AGENT_GUIDE_URL__, настрой MCP и установи skill, если мой клиент его поддерживает. Попроси меня выписать персональный токен. После подключения проверь доступность инструментов и состояние студии. Не создавай и не отправляй пост для проверки подключения.

Можно передать и ссылку на эту страницу. Инструкции открыты без входа, а рабочие инструменты требуют токен. Публичная ссылка сама по себе не предоставляет доступ к вашим черновикам.

Создайте персональный токен

  1. Войдите в RichPost через Telegram и откройте меню своей учётки.
  2. Выберите «Токены API и MCP» → «Создать токен». Укажите понятное название клиента и срок действия.
  3. Выберите минимальные права для задачи. Для подготовки текстов обычно достаточно «Черновики».
  4. Сохраните показанный один раз токен в защищённых настройках клиента. Не помещайте его в ссылку, публичный чат, скриншот или репозиторий.

Как выбрать права

  • Чтение: просмотр доступных данных без изменения черновиков.
  • Черновики: работа с текстами, черновиками и шаблонами без права публикации.
  • Публикация: действия отправки, когда они нужны для согласованной задачи.

Агент не выпускает токен вместо вас и не использует для подключения токен бота, пароль или код Telegram. Вы можете отозвать персональный токен в том же меню. Техническое разрешение на публикацию не заменяет ваше поручение отправить конкретный пост.

Проверьте подключение без публикации

После сохранения настроек клиенту может потребоваться перезапуск или подтверждение нового MCP сервера. Агент должен получить список инструментов и успешно вызвать studio_status. Запись в конфигурации и ответ HTTP 200 сами по себе ещё не подтверждают, что инструмент выполнился без ошибки.

При отказе проверьте срок действия и роль токена, адрес сервера и способ передачи секрета в клиент. Не отправляйте токен на другой адрес вслед за неожиданным перенаправлением. Для отдельного клиента удобнее отдельный токен: его можно отозвать, не отключая остальные подключения.

Первая рабочая задача

Начните с черновика: «Подготовь анонс встречи, покажи предпросмотр и сохрани для моей проверки». Уточните факты, ссылки и желаемое оформление. Перед публикацией согласуйте окончательный текст, канал и время. Канал подключается в редакторе отдельно; выдача токена не добавляет его автоматически.

Для текста используйте руководство по Markdown, для данных — таблицы, для выбранного времени — отложенные посты.

Частые вопросы

Подойдёт ли любой чат с ИИ?

Нет. Клиент должен поддерживать удалённый MCP через HTTP с персональным bearer токеном. Поддержка skill и способ хранения секрета зависят от клиента.

Можно ли разрешить только подготовку черновиков?

Да. Выберите роль «Черновики». Для просмотра достаточно роли «Чтение», а право публикации выдаётся отдельно.

Нужно ли передавать агенту токен Telegram бота?

Нет. Для подключения используется персональный API/MCP токен RichPost. Токен бота, пароль и код входа Telegram для этого не нужны.

Как отключить подключение?

Отзовите его персональный токен в меню «Токены API и MCP». При необходимости удалите запись MCP сервера из настроек клиента.
