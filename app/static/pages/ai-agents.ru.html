Дайте агенту ссылку.
Работайте с постами из чата.

Агент может готовить черновики, показывать предпросмотр и заполнять ваши шаблоны. Вы сможете продолжить редактирование в RichPost.

Что написать агенту

Скопируйте сообщение в Codex, Claude Code или другой клиент с поддержкой удалённых MCP-подключений:

Подключи мне RichPost. Прочитай инструкцию для агента по адресу __AGENT_GUIDE_URL__, настрой MCP и установи skill, если мой клиент его поддерживает. Попроси меня выписать персональный токен. После подключения проверь, что инструменты работают.

Можно отправить и просто ссылку на эту страницу. Здесь есть ссылки на инструкции, которые агент сможет прочитать без входа.

Один шаг остаётся за вами: токен

  1. Войдите в RichPost через Telegram.
  2. Откройте меню своей учётки → «Токены API и MCP» → «Создать токен». Укажите название клиента и срок действия.
  3. Для работы с текстами и шаблонами выберите «Черновики». «Чтение» подходит для просмотра, «Публикация» — когда хотите разрешить агенту отправлять посты.
  4. Сохраните показанный один раз токен в настройках секретов своего клиента по инструкции агента. Не размещайте его в публичном чате или репозитории.

Агент сам токен не выписывает. Вы можете отозвать его в том же меню. Разрешение на публикацию не означает просьбу отправить конкретный пост — сначала согласуйте текст и канал.

Как понять, что всё подключилось

Агент должен проверить соединение и доступность инструментов, а затем сообщить результат. Иногда клиенту нужен перезапуск или подтверждение нового подключения. Если клиент поддерживает только OAuth-вход, потребуется другой способ подключения с персональным токеном.

После настройки попробуйте: «Подготовь черновик анонса», «Покажи предпросмотр» или «Создай пост по моему шаблону». Для публикации подключите свой канал в редакторе и выдайте боту необходимые права.
