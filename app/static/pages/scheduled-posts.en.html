Schedule posts for Telegram channels

Prepare a post in advance and choose a time. The RichPost server sends it, so you can close the app after saving the schedule. The queue and delivery outcome remain available in Posts.

Check the setup before scheduling

Connect a channel you manage and make the bot an administrator with permission to post. The studio checks both your permissions and the bot's permissions. Signing in with Telegram is not enough: the channel must be connected to your account and selected for this post.

Prepare the text, media, tables and buttons before choosing a time. A private Telegram preview helps catch mistakes before publication. If you manage several channels, confirm the recipient list carefully so an announcement does not end up in the wrong place.

Put a post in the queue

  1. Create or open a draft. Check its active format and preview. Start the bot, then send a private preview if you want to inspect the result in Telegram.
  2. Open Channels in the header and select one or several recipients. Check the names again.
  3. Open the menu beside Publish and select the scheduling action. Choose a future date and time.
  4. Check the time zone shown beside the time field, then confirm the schedule.
  5. Open Posts and its scheduled filter. Check the time and channel for every entry. You can now close the app.

Time zones and delivery time

The scheduling form uses the browser's time zone and displays it beside the field. It may differ from your usual zone when you travel or use a remote computer. If the event is in another region, first convert its time to the zone displayed in the form.

Check the queue after saving. The selected time schedules a sending attempt; it does not guarantee that every reader will see the post at the exact same second. The availability of the server, Telegram and valid channel permissions all affect delivery.

Change a scheduled post

Text, media and buttons

Find the entry in Posts and choose Edit. Confirm that the editor is working with that entry, then use the action to update the post. The regular Publish action creates a separate publication. If another window has changed the entry, read the latest version before replacing it.

Time or cancellation

Reschedule changes the time of a waiting entry. Cancel removes it from the queue. Refresh the list after the action and check the result. Once sending has started, changing the queue cannot recall a message already accepted by Telegram.

Check the outcome in every channel

After the scheduled time, open Posts and the channel itself. When several channels are selected, each recipient has its own outcome. A successful send to one channel does not prove delivery to all the others.

If the server was unavailable for too long, an entry can become missed. Check the service state and choose a new suitable time. If Telegram refused the send because of permissions, fix those permissions and confirm the message was not delivered before sending it again.

An ambiguous network error can occur after Telegram accepted the post. The studio does not retry that send automatically. Check the channel first: publishing again without checking may create a duplicate.

For formatting, use Markdown with preview or tables. An AI agent can prepare the draft while you agree on the final text, channel and time before publishing.

Frequently asked questions

Does the app need to stay open?

No. The RichPost server sends saved scheduled posts. The server must be running and channel permissions must remain valid.

Which time zone does the form use?

The form uses the browser time zone and displays it beside the time field. Check it before confirming, especially when travelling or using a remote computer.

Can I reschedule or cancel a post?

Yes, while the entry is waiting to be sent. Use Reschedule or Cancel in Posts, then inspect the updated queue.

What should I do if a post may have been sent?

Check the Telegram channel first. An ambiguous error does not prove the message is absent, so the studio does not retry it automatically.
