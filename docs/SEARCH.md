# Публичные страницы и проверка поиска

При `STUDIO_PUBLIC=on` и `STUDIO_LANDING_URL=https://example.com` главная на `/` русская, `/en/` — английская. Язык задаётся URL, без перенаправления по IP или Accept-Language. Взаимные `hreflang` включают обе версии и `x-default`; каждая версия канонична сама для себя. Английские ссылки в приложение передают `?lang=en`.

Три руководства находятся на `/features/telegram-tables/`, `/features/telegram-markdown/`, `/features/scheduled-posts/`. Английские версии имеют префикс `/en`. Инвентарь `app/public_site.py` одновременно ограничивает публичные адреса и формирует sitemap. Файлы в `app/static/pages/` — редакционные материалы, не данные учёток.

`/robots.txt` разрешает обход, чтобы робот мог прочесть `noindex`. На основном домене он указывает `/sitemap.xml`: только главная, руководства и их переводы. Рабочий домен, API, рендеры и локальные `/landing`, `/landing/en/` получают `X-Robots-Tag: noindex, nofollow`; HTML редактора также имеет robots-метатег. Данные учёток по-прежнему защищает авторизация. Неизвестная публичная страница возвращает 404; известные адреса приложения перенаправляются на рабочий домен.

Демонстрационный пост главной обёрнут в `data-nosnippet`. Его декоративный заголовок не входит в H2/H3 страницы. FAQ предназначен для читателя; обещаний расширенного поискового сниппета нет.

После выкладки проверить снаружи:

1. HTTPS и ответ 200 главной, `/en/` и всех URL из sitemap; canonical, взаимные hreflang, отсутствие noindex на публичном домене. Проверить HTTP → HTTPS и при использовании `www` выбрать один хост и постоянный редирект.
2. `/robots.txt` и `/sitemap.xml`: 200, правильный Content-Type, только основной публичный домен. Несуществующий адрес: 404. Рабочий домен: noindex и сохранённая авторизация.
3. В существующих Google Search Console и Яндекс Вебмастере проверить URL главной, обход, выбранный canonical, индексацию и ошибки. Передать sitemap и запросить переобход изменённых страниц. Аналогично можно использовать Bing Webmaster Tools. Отправка URL и sitemap не доказывает индексацию.
4. Отдельно измерить мобильную загрузку и Core Web Vitals. Скриншоты и тест отсутствия переполнения не являются замером LCP, INP или CLS.
5. Следить за показами, кликами, переходами в приложение и успешным началом работы. Не делать вывод о полном числе страниц по оператору `site:`.

Коды подтверждения вебмастеров, контакт поддержки, тарифы и юридические условия публикуются только по сведениям владельца. Здесь нет выдуманных реквизитов, автоматической регистрации кабинетов, отправки IndexNow или обещания поисковых позиций.

Основания: [языковые версии Google](https://developers.google.com/search/docs/specialty/international/localized-versions), [noindex и data-nosnippet](https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag). Для просмотра точного статуса индексации нужен доступ владельца к кабинетам.
