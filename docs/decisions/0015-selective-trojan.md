# 0015. Выборочный Trojan через внутренний HTTP-прокси

Для VPS с ограниченным исходящим доступом используем необязательный sing-box рядом с приложением. Он поддерживает существующий Trojan-профиль оператора, HTTP CONNECT для Python и Go и правила по имени назначения. Образ закреплён по digest; контейнеру не нужны TUN, host network и права на изменение маршрутов сервера.

Отдельная настройка `TG_PROXY_URL` применяется только к Bot API. Caddy получает свой `ACME_PROXY_URL`. Это позволяет обойтись без общего VPN сервера и сохранить прямой маршрут и защиту загрузок медиа от запросов во внутреннюю сеть (ADR 0012). В sing-box через Trojan идут только Telegram Bot API и домены центра сертификации; остальные назначения идут напрямую. При недоступности Trojan эти выбранные направления не переключаются автоматически на прямое соединение.

Профиль остаётся приватным файлом VPS. Активация проверяет временный прокси реальными read-only запросами ACME и `getMe`, а затем переключает настройки. Проверки не публикуют сообщения. Тесты используют локальные подставные серверы и не обращаются к настоящему Telegram.
