# 0024. Паки кастомных эмодзи и tlottie для анимаций

Дата: 2026-10-31.

**Решение.** Паки кастомных эмодзи настраиваются в меню аккаунта по короткому коду набора (`t.me/addemoji/<код>`) и живут в мета учётки (`emoji-packs`, `emoji-pack:<имя>`) — без новой миграции: это настройки, а не посты. Картинки скачиваются Bot API-цепочкой (`getStickerSet` → `getCustomEmojiStickers` → `getFile` → `GET /file/bot<token>/<path>`) в `accounts/<uid>/emoji-cache/` — вне `media/`, чтобы лимит загрузок и уборка неиспользуемых файлов их не трогали (пак — конфигурация, а не пользовательская загрузка). MTProto не нужен: перечисленных методов Bot API достаточно, они добавлены в `READ_METHODS` публичных учёток.

Рендер в предпросмотре: статичные эмодзи — webp-миниатюра (`/api/emoji/img/<id>`), видео-эмодзи — родной `<video autoplay loop muted>` (`/api/emoji/file/<id>`), .tgs-анимации — [tlottie](https://github.com/dkaraush/tlottie) (Rust/WASM, MIT, без зависимостей; wasm-сборки закоммичены автором, вендорим с коммита `92df98dc`, обновление вручную). tlottie выбран вместо lottie-web/dotlottie: он микро-оптимизирован на анимациях из Telegram и понимает их расширения (fitz-модификатор, color replacements), которые стандартные Lottie-плееры не рисуют; dotlottie тянет ~700 КБ wasm и не понимает fitz. WASM — единственный в студии: CSP `script-src` получает узкое `'wasm-unsafe-eval'` (компиляция wasm, не eval скриптов), glue (`vendor/tlottie/tlottie.js`) и оба .wasm грузятся лениво — только когда в предпросмотре появился .tgs-эмодзи. Без настроенных паков или при ошибке загрузки остаётся замена текстом (`alternative_text`), как показывает Telegram.

**Границы.** Панель вставляет чип-сущность `custom_emoji` с `custom_emoji_id` — в Telegram уходят только id, картинки нужны только предпросмотру. Анимация в предпросмотре работает только когда редактор знает пак сущности (мета паков в `emojiKinds`); вставленный агентом или вручную id без пака рисуется статикой или текстом. Ежедневная уборка кэша не предусмотрена: файлы на эмодзи малы и переиспользуются при возврате пака. Список «установленных» наборов Bot API не отдаёт — только конкретный набор по имени.
