# 0021. Подключение агента по ссылке и ненавязчивое предложение PWA

2026-10-30, продолжение PWA и персональных токенов.

**Решение.** Установку приложения предлагаем автоматически исчезающим уведомлением в углу экрана после взаимодействия и 45 секунд на странице, если браузер предоставил native prompt либо это Safari на iPhone/iPad. Во время ввода, открытого диалога, скрытой вкладки и на экране входа уведомление не появляется. Игнорированное уведомление исчезает само и не повторяется до следующей сессии; явное «Не предлагать» запоминается навсегда, пауза 30 дней из прежней карточки тоже учитывается. Если хранилище недоступно, автоматическое предложение выключено. Постоянных кнопок установки нет нигде — ни в шапке, ни на экране входа, ни в меню учётки; установить всегда можно средствами браузера.

Правка 2026-10-31 по отзыву: вместо немодальной карточки внизу экрана, которую принимали за постоянный футер с кнопкой, — исчезающее уведомление; явный отказ запоминается навсегда, а не на 30 дней; ручной пункт установки в меню учётки убран.

Native `prompt()` вызывается только по нажатию на установку: браузер требует пользовательскую активацию. Уведомление не перехватывает случайный клик по редактору. PWA по-прежнему кэширует только публичный offline-экран.

Для сценария «дай агенту ссылку и попроси подключить» доступны `/llms.txt`, `/llms-full.txt`, `/agents.txt`, `/agents.json`, `/agents.md`, `/skills/richpost/SKILL.md`. Последний — самодостаточный текстовый service-consumption skill; инструкции разработки репозитория не публикуются. `agents.md` содержит настройку и критерий завершения, skill — дальнейшую работу. `llms-full.txt` собирается из тех же исходников. Страницы `/features/ai-agents/` и `/en/features/ai-agents/` дают человеку готовый запрос и путь к выпуску токена; они связаны с лендингом и sitemap. `rel=describedby` и HTTP Link ведут к документации.

Адреса строятся из `STUDIO_URL`/`STUDIO_LANDING_URL`, не из Host/Forwarded. Публичны только фиксированные пути с документацией; нет выдачи произвольных файлов, данных учёток или секретов. Авторизация MCP и API не меняется. На рабочем домене сохраняется noindex; индексируемая точка входа находится на домене лендинга.

**Человеческий шаг.** Агент просит пользователя самому создать персональный токен в «Токены API и MCP», по умолчанию `draft`, и сохранить его в приватной настройке клиента или его окружении. Он не автоматизирует Telegram-вход и выпуск токена, не ищет операторские ключи. Подключение завершено после MCP initialization, `tools/list` и успешного `studio_status` через выбранный клиент. Записанный конфиг, прямой HTTP-тест или ожидающий перезапуска клиент не выдаются за проверенную интеграцию. Тестовая публикация для подключения не нужна.

**Границы форматов.** `llms.txt` — предложение формата документации, `agents.txt` — draft спецификация обнаружения возможностей, а не механизм повышения поисковых позиций или выдачи прав. Объявляем только существующие MCP/Skills. Не добавляем фиктивные OAuth discovery, A2A card, WebMCP и не внедряем новые рантайм-зависимости. Поддержка автоматического обнаружения и установки зависит от клиента; текст предлагает использовать его штатную конфигурацию, сохраняя остальные серверы и пользовательские skills.

Источники, сверенные при реализации: [llms.txt](https://llmstxt.org/), [agents.txt draft](https://github.com/agents-txt/agents-txt/blob/main/app/site/src/content/spec/AGENTS-TXT-STANDARD.md), [Agent Skills](https://agentskills.io/specification), [user activation для PWA prompt](https://developer.mozilla.org/en-US/docs/Web/API/BeforeInstallPromptEvent/prompt), [Codex MCP](https://learn.chatgpt.com/docs/extend/mcp#streamable-http-servers), [Claude Code MCP](https://code.claude.com/docs/en/mcp#environment-variable-expansion-in-mcp-json).
