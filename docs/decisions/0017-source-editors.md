# 0017. Текстовые редакторы с подсказками

2026-10-30. Пользователь попросил подсветку, подсказки и автодополнение для текстовых режимов, предложил рассмотреть Monaco и исключил миникарту. После сравнения явно выбрал CodeMirror 6.

**Выбор.** CodeMirror поддерживает мобильный ввод. У Monaco [мобильные браузеры официально не поддерживаются](https://github.com/microsoft/monaco-editor/blob/main/README.md), а AMD-подключение объявлено устаревшим. Берём только HTML, Markdown, JSON и нужные возможности редактора. Миникарта не подключается.

**Поставка.** Обычные ES-модули приложения остаются без сборки. Закреплённые dev-зависимости и `scripts/vendor-code-editor.mjs` нужны только для обновления готового vendor ESM, его типов и лицензий. `npm run test:source` проверяет воспроизводимость артефактов. В Docker не добавляется Node, CDN и внешние скрипты не нужны. Bundle загружается при появлении текстового режима; при ошибке загрузки сохраняется textarea. CSP не ослабляется.

**Состояние и подсказки.** Компонент Lit не импортирует состояние поста. HTML/Markdown-сниппеты и дополнительные теги берутся из существующего каталога; JSON — из текущей спецификации, включая новые поля, объединения типов и значения дискриминатора. Редактор не запрещает неизвестные поля и не исправляет payload сам. Неприменённый JSON сохраняется в черновике как `_studio.buffers.json`, но не попадает в отправляемый пост до явного применения. При загрузке другого документа сбрасывается локальная история отмены, включая резервный textarea.
