# 0020. Установка, связанные форматы и шаблоны постов

2026-10-30. Пользователь запросил PWA, взаимный перенос всего поста между визуалом/Markdown/HTML и шаблоны с формой заполнения. Общие точки интеграции редактора потребовали одной интеграционной ветки; вертикальные срезы реализованы отдельно.

PWA использует стандартный manifest и service worker без зависимостей. Offline-кэш содержит только публичную справочную страницу. Сохранение и отправка требуют сети: фоновые повторы публикации противоречили бы существующей политике MayHaveGone, а приватный кэш потребовал бы отдельного проектирования границы учёток. Обновления не вызывают reload и не прерывают несохранённый ввод. Требования установки: [MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable).

Преобразование запускается при выборе вкладки, целиком в браузере. Markdown разбирается тем же кодом, что и предпросмотр; сложные блоки сериализуются разрешённым HTML. Явные адаптеры проверяют поля и отказывают при неподдерживаемой конструкции, сохраняя исходник. Палитра остаётся построенной из спецификации: список адаптеров не ограничивает доступные блоки или отправку новых полей. Независимый JSON применяется только явно. Старые альтернативные буферы резервируются лишь перед первой перезаписью, без дублирования активного буфера на обычном сохранении.

Шаблон — отдельная запись account-local SQLite, а не специальный черновик или запись localStorage. Переменные `{{key}}` заменяются только в строковых значениях; формы описываются полями с подписью, типом, обязательностью и default. Подстановка сохраняет литеральное значение с экранированием по формату; сложные позиции, для которых это не обеспечено, отвергаются. Версия проверяется при изменении, удалении и заполнении. Результат — новый непубликуемый черновик без каналов исходника. Размер заполнения проверяется до построения потенциально большого результата. Медиа шаблонов участвуют в поиске используемых файлов.
